# 实验设计与评测操作

## 公平对比

固定测试会议、输出结构、摘要语言和文本归并模型。路线1和2使用相同混音；路线3使用同一场会议的独立麦克风，是“增强输入条件”实验，不能据此声称算法在相同单通道输入上更好。统计会议级均值、标准差和样本数。测试前固定提示词、ASR 版本、块长、随机条件；重复运行至少3次观察 API 输出波动。

| 实验 | 输入 | 改动因素 | 目的 |
|---|---|---|---|
| T | 人工转写 | 去除ASR错误 | 定位摘要模块上限 |
| A | 混音 | 本地ASR+文本LLM | 主基线 |
| B | 相同混音 | 音频模型+相同文本LLM | 比较直接听音 |
| C | 同场独立分轨 | 录音条件+说话人元数据 | 分析重叠与归属问题 |
| A-small/A-large | 相同混音 | 仅ASR模型 | 识别质量的影响 |
| B-30/B-60 | 相同混音 | 仅音频块长 | 信息完整性与成本 |

## 指标定义

中文 ASR：CER=(替换+删除+插入)/参考字数；英语 ASR 用 WER。脚本统一 NFKC、转小写、去标点，中文去空格。错误率可能大于1，不应强行截到100%。全会议多说话人转写按起始时间串联的 WER 会受重叠顺序影响，应明确其局限；更严谨的说话人评测需独立引入 cpWER/SA-WER，而本项目没有实现这两项。

摘要：脚本实现 ROUGE-L 的最长公共子序列 F1，中文按字、英文按词。实现没有词干化，不能与任意论文分数直接比较。英文参考摘要和中文生成结果不能直接计算有意义的 ROUGE；AMI 实验如采用中文摘要，以人工语义评价为主，或固定提示词让所有方法输出英文后再评测。不要把模型翻译出的参考摘要当作人工金标准而不注明。

人工指标：两名标注者独立核查全部决定和行动项，第三轮讨论分歧。报告决策精确率/召回率、行动项匹配F1、负责人正确率、截止日期正确率、无依据陈述比例。先制订匹配规则：动作与对象语义一致才匹配，负责人/日期单独计分；缺失和 null 的处理必须统一。概述也要核查，不能只检查列表。

引用存在性：代码会拒绝不存在的 evidence_ids，但存在的编号可能不支持结论。另行抽查“引用是否真的支持条目”。路线2只能回溯到音频块，通常比路线1的片段时间范围粗；不宣称精确词级对齐。

效率：记录总耗时/音频时长=RTF；首次下载与冷启动要单独标记。`raw_calls.json` 的 usage 是厂商实际返回的字段，若缺失写 null，不补造。费用按运行当天、对应地域和模型的实际账单核算，区分文本与音频价格。

重叠：本工具定义为“至少两名不同说话人同时活动时长 / 至少一人活动时长”。某些论文分母用整场录音时长，两者不可混用。

## 评测命令

```powershell
python -m scripts.export_text outputs/r1_001/segments.json outputs/r1_transcript.txt
python -m scripts.evaluate --task asr --unit char --reference data/reference_transcript.txt --prediction outputs/r1_transcript.txt --out outputs/cer.json
python -m scripts.export_text outputs/r1_001/summary.json outputs/r1_summary.txt
python -m scripts.evaluate --task summary --unit char --reference data/reference_summary.txt --prediction outputs/r1_summary.txt --out outputs/rouge.json
```

参考纯文本只用于评测或明确标记的 T 实验，不能传给 A/B/C 来“纠错”，否则数据泄漏。路线2没有逐字稿，因此 CER/WER 填“不可用”。demo 的人工摘要不得混入真实结果。
